Part 4 — Serialisation¶

A nested dictionary can be saved to a file and read back, in JSON or with pickle. This part saves the heating schedule of the house, which maps an hour of the day to a temperature, and explains what each format keeps.

The thermostat of each room switches at given hours. The hours are integers, not strings:

>>> from ndict_tools import NestedDictionary
>>> schedule = NestedDictionary({
...     "living room": {"thermostat": {7: 20.5, 22: 17.0}},
...     "bedroom": {"thermostat": {6: 19.0, 21: 16.5}},
... })

JSON¶

to_json() writes the dictionary to a JSON file. indent makes the file easier to read:

>>> schedule.to_json("schedule.json", indent=2)
>>> from pathlib import Path
>>> print(Path("schedule.json").read_text())
{
  "living room": {
    "thermostat": {
      "[7]": 20.5,
      "[22]": 17.0
    }
  },
  "bedroom": {
    "thermostat": {
      "[6]": 19.0,
      "[21]": 16.5
    }
  }
}

JSON only allows string keys, so the hours are written as "[7]", "[22]" and so on. from_json() reads them back as integers:

>>> restored = NestedDictionary.from_json("schedule.json")
>>> restored[["living room", "thermostat", 7]]
20.5
>>> restored == schedule
True

The file holds the content only: neither the class nor the default_setup. The result has the class on which from_json is called and, unless default_setup is given, the default configuration of that class, as with from_dict(). The same file can give a StrictNestedDictionary, or a dictionary printed with an indentation:

>>> from ndict_tools import StrictNestedDictionary
>>> checked = StrictNestedDictionary.from_json("schedule.json")
>>> checked.isomorph(schedule)
True
>>> printable = NestedDictionary.from_json(
...     "schedule.json",
...     default_setup={"indent": 2, "default_factory": NestedDictionary},
... )
>>> printable.default_setup[0]
('indent', 2)

Keys of type str, int, float and bool, and tuples and frozensets of such values, survive the round trip. A string key that looks like an encoded key is escaped, so it stays a string:

>>> labels = NestedDictionary({7: "wake up", "[7]": "a label"})
>>> labels.to_json("labels.json")
>>> NestedDictionary.from_json("labels.json").to_dict()
{7: 'wake up', '[7]': 'a label'}

A key of another type raises StackedTypeError. The values must be types that JSON can write: strings, numbers, booleans, None, lists and dictionaries.

>>> NestedDictionary({None: "unknown hour"}).to_json("unknown.json")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedTypeError: JSON key encoding is not supported for type NoneType. Supported types: str, int, float, bool, tuple, frozenset. (expected: str, got: NoneType)

Pickle¶

Warning

Loading a pickle file can run arbitrary code. Only load files that you wrote yourself or that come from a source you trust. to_pickle and from_pickle emit a UserWarning as a reminder; the examples below hide it.

to_pickle() writes the whole object, and next to it a .sha256 file that holds the digest of the pickle file:

>>> schedule.to_pickle("schedule.pkl")
>>> sorted(path.name for path in Path().glob("schedule.pkl*"))
['schedule.pkl', 'schedule.pkl.sha256']

from_pickle() checks the digest, then returns the object with its class and its default_setup, with no argument to give:

>>> NestedDictionary.from_pickle("schedule.pkl") == schedule
True

If the file was changed after it was written, or if the .sha256 file is missing, from_pickle raises StackedValueError before loading anything:

>>> with open("schedule.pkl", "ab") as file:
...     _ = file.write(b"tampered")
>>> NestedDictionary.from_pickle("schedule.pkl")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedValueError: SHA-256 digest mismatch for 'schedule.pkl': ...

verify=False skips the check, for a file whose origin you trust and whose digest file was not kept.

The object in the file must be an instance of the class on which from_pickle is called, or of a subclass. Otherwise StackedTypeError is raised:

>>> schedule.to_pickle("schedule.pkl")
>>> StrictNestedDictionary.from_pickle("schedule.pkl")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedTypeError: 'schedule.pkl' does not contain an instance of StrictNestedDictionary (expected: StrictNestedDictionary, got: NestedDictionary)

Use JSON for configuration files, data exchanged with other programs, and anything that comes from outside. Use pickle to keep Python objects between two runs of your own program.
