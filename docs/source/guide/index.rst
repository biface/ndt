Guide
=====

This guide shows how to use the public interface of **ndict-tools**: the
classes and methods you import from the ``ndict_tools`` package. It follows
one example from page to page, the inventory of a house: floors contain
rooms, rooms contain equipment, and equipment has settings. Each page builds
the part of the house it needs, so every example can be copied and run on its
own.

The parts build on each other. Read them in order, or go straight to the one
you need:

.. toctree::
   :maxdepth: 2

   getting_started
   paths
   serialization
   extending

The guide explains what to call and what you get back. How the package
represents a nested dictionary, and why the methods behave as they do, is the
subject of the :doc:`/concepts/index` section.
