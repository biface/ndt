Couverture¶

La couverture répond à la question : quelle part d’un dictionnaire imbriqué un ensemble de chemins donné décrit-il ?

C’est utile lorsque vous travaillez avec un CompactPathsView partiel ou défini indépendamment, et que vous voulez savoir quelle part d’un dictionnaire cible il décrit.

Toutes les méthodes de couverture comparent deux ensembles de chemins : les chemins développés à partir de la structure compacte, notés S ci-dessous, et les chemins du dictionnaire, notés T.

  • coverage() renvoie la part de T présente dans S : le nombre de chemins communs aux deux ensembles, divisé par le nombre de chemins de T. Les chemins de S absents de T ne la modifient pas ; la valeur est donc toujours comprise entre 0.0 et 1.0.

  • is_covering() renvoie True lorsque les deux ensembles sont égaux.

  • uncovered_paths() énumère les chemins de T absents de S.

  • missing_paths() énumère les chemins de S absents de T.

coverage() == 1.0 signifie donc que chaque chemin du dictionnaire est décrit, tandis que is_covering() exige en plus que la structure ne décrive aucun autre chemin.

Couverture complète¶

Un CompactPathsView construit directement à partir d’un dictionnaire le couvre toujours entièrement :

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({"a": {"b": 1, "c": 2}, "d": 3})
>>> cpaths = nd.compact_paths()
>>> cpaths.is_covering(nd)
True
>>> cpaths.coverage(nd)
1.0

Couverture partielle¶

Affectez une structure réduite pour simuler une couverture partielle :

>>> cpaths.structure = [['a', 'b']]  # seulement les chemins ['a'] et ['a', 'b']
>>> cpaths.is_covering(nd)
False
>>> cpaths.coverage(nd)  # 2 chemins couverts sur 4
0.5

Repérer les chemins non couverts¶

uncovered_paths() renvoie les chemins présents dans le dictionnaire mais absents de la structure compacte :

>>> cpaths.uncovered_paths(nd)
[['a', 'c'], ['d']]

Repérer les chemins manquants¶

missing_paths() renvoie les chemins présents dans la structure compacte mais absents du dictionnaire, ce qui est utile lorsque la structure a été définie à la main et peut contenir des entrées invalides :

>>> cpaths.structure = [['a', 'b', 'c'], ['d'], ['e']]  # 'e' n’existe pas
>>> cpaths.missing_paths(nd)
[['e']]

Chemins en trop¶

Une structure qui décrit tous les chemins du dictionnaire, et d’autres encore, a une couverture complète, mais elle n’est pas couvrante, puisque les deux ensembles de chemins diffèrent :

>>> cpaths.structure = [['a', 'b', 'c'], ['d'], ['e']]
>>> cpaths.coverage(nd)  # les 4 chemins de nd sont décrits
1.0
>>> cpaths.is_covering(nd)  # mais ['e'] n’est pas un chemin de nd
False

Exemple pratique¶

Supposons que vous receviez une spécification décrivant la structure attendue d’un dictionnaire imbriqué, et que vous vouliez vérifier que des données reçues la respectent :

>>> from ndict_tools import NestedDictionary
>>> # Structure attendue
>>> expected = NestedDictionary({
...     "user": {"name": None, "email": None},
...     "settings": {"theme": None},
... })
>>> spec = expected.compact_paths()
>>> # Données reçues
>>> payload = NestedDictionary({
...     "user": {"name": "Alice", "email": "alice@example.com"},
...     "settings": {"theme": "dark", "lang": "fr"},
... })
>>> spec.is_covering(payload)  # 'settings.lang' est en trop
False
>>> spec.uncovered_paths(payload)  # chemins des données absents de la spécification
[['settings', 'lang']]
>>> spec.missing_paths(payload)  # aucun chemin de la spécification ne manque
[]
>>> payload.compact_paths().coverage(expected)  # les données couvrent toute la spécification
1.0
