Partie 4 — Sérialisation¶

Un dictionnaire imbriqué peut être enregistré dans un fichier puis relu, en JSON ou avec pickle. Cette partie enregistre la programmation du chauffage de la maison, qui associe une heure de la journée à une température, et explique ce que conserve chaque format.

Le thermostat de chaque pièce change de consigne à des heures données. Les heures sont des entiers, pas des chaînes :

>>> from ndict_tools import NestedDictionary
>>> schedule = NestedDictionary({
...     "living room": {"thermostat": {7: 20.5, 22: 17.0}},
...     "bedroom": {"thermostat": {6: 19.0, 21: 16.5}},
... })

JSON¶

to_json() écrit le dictionnaire dans un fichier JSON. indent rend le fichier plus lisible :

>>> schedule.to_json("schedule.json", indent=2)
>>> from pathlib import Path
>>> print(Path("schedule.json").read_text())
{
  "living room": {
    "thermostat": {
      "[7]": 20.5,
      "[22]": 17.0
    }
  },
  "bedroom": {
    "thermostat": {
      "[6]": 19.0,
      "[21]": 16.5
    }
  }
}

JSON n’autorise que des clés de type chaîne ; les heures sont donc écrites "[7]", "[22]", et ainsi de suite. from_json() les relit comme des entiers :

>>> restored = NestedDictionary.from_json("schedule.json")
>>> restored[["living room", "thermostat", 7]]
20.5
>>> restored == schedule
True

Le fichier ne contient que le contenu : ni la classe ni le default_setup. Le résultat a la classe sur laquelle from_json est appelée et, sauf si default_setup est fourni, la configuration par défaut de cette classe, comme avec from_dict(). Le même fichier peut donner un StrictNestedDictionary, ou un dictionnaire affiché avec une indentation :

>>> from ndict_tools import StrictNestedDictionary
>>> checked = StrictNestedDictionary.from_json("schedule.json")
>>> checked.isomorph(schedule)
True
>>> printable = NestedDictionary.from_json(
...     "schedule.json",
...     default_setup={"indent": 2, "default_factory": NestedDictionary},
... )
>>> printable.default_setup[0]
('indent', 2)

Les clés de type str, int, float et bool, ainsi que les tuples et les frozensets de telles valeurs, survivent à l’aller-retour. Une clé chaîne qui ressemble à une clé encodée est échappée, et reste donc une chaîne :

>>> labels = NestedDictionary({7: "wake up", "[7]": "a label"})
>>> labels.to_json("labels.json")
>>> NestedDictionary.from_json("labels.json").to_dict()
{7: 'wake up', '[7]': 'a label'}

Une clé d’un autre type lève une StackedTypeError. Les valeurs doivent être de types que JSON sait écrire : chaînes, nombres, booléens, None, listes et dictionnaires.

>>> NestedDictionary({None: "unknown hour"}).to_json("unknown.json")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedTypeError: JSON key encoding is not supported for type NoneType. Supported types: str, int, float, bool, tuple, frozenset. (expected: str, got: NoneType)

Pickle¶

Avertissement

Charger un fichier pickle peut exécuter du code arbitraire. Ne chargez que des fichiers que vous avez écrits vous-même ou qui proviennent d’une source de confiance. to_pickle et from_pickle émettent un UserWarning pour le rappeler ; les exemples ci-dessous le masquent.

to_pickle() écrit l’objet entier et, à côté, un fichier .sha256 qui contient l’empreinte du fichier pickle :

>>> schedule.to_pickle("schedule.pkl")
>>> sorted(path.name for path in Path().glob("schedule.pkl*"))
['schedule.pkl', 'schedule.pkl.sha256']

from_pickle() vérifie l’empreinte, puis renvoie l’objet avec sa classe et son default_setup, sans argument à fournir :

>>> NestedDictionary.from_pickle("schedule.pkl") == schedule
True

Si le fichier a été modifié après son écriture, ou si le fichier .sha256 est absent, from_pickle lève une StackedValueError avant de charger quoi que ce soit :

>>> with open("schedule.pkl", "ab") as file:
...     _ = file.write(b"tampered")
>>> NestedDictionary.from_pickle("schedule.pkl")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedValueError: SHA-256 digest mismatch for 'schedule.pkl': ...

verify=False ignore la vérification, pour un fichier dont vous connaissez l’origine et dont le fichier d’empreinte n’a pas été conservé.

L’objet contenu dans le fichier doit être une instance de la classe sur laquelle from_pickle est appelée, ou d’une sous-classe. Sinon, une StackedTypeError est levée :

>>> schedule.to_pickle("schedule.pkl")
>>> StrictNestedDictionary.from_pickle("schedule.pkl")
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedTypeError: 'schedule.pkl' does not contain an instance of StrictNestedDictionary (expected: StrictNestedDictionary, got: NestedDictionary)

Utilisez JSON pour les fichiers de configuration, les données échangées avec d’autres programmes et tout ce qui vient de l’extérieur. Utilisez pickle pour conserver des objets Python entre deux exécutions de votre propre programme.
