serialize — Infrastructure de sérialisation¶

Avertissement

Module interne — peut changer sans préavis. N’importez pas ces fonctions directement. Utilisez à la place les méthodes de sérialisation publiques de NestedDictionary (to_json, from_json, to_pickle, from_pickle).

Infrastructure de sérialisation privée de ndict_tools.

Ce module ne fait pas partie de l’API publique. Il fournit les fonctions de bas niveau utilisées par les méthodes de sérialisation de _StackedDict (to_json, from_json, to_pickle, from_pickle).

Contenu¶

  • _encode_key / _decode_key : encodage des clés JSON entre crochets

  • NestedDictionaryEncoder  : sous-classe de json.JSONEncoder

  • _make_decoder_hook  : fabrique pour object_pairs_hook

  • _pickle_dump / _pickle_load : fonctions pickle avec vérification SHA-256

Décisions de conception¶

  • Encodage des clés JSON (décision de conception #87) : JSON impose des clés de type chaîne ; Python accepte des clés hachables quelconques. Les clés qui ne sont pas des chaînes sont écrites entre crochets (par exemple [42], [3.14], [True], [(1, 2)], [frozenset{1, 2}]). Une clé chaîne qui commence par [ est échappée par une barre oblique inverse ([42] → \[42]), de sorte qu’elle ne peut pas être relue comme une clé encodée. Le décodage utilise ast.literal_eval pour reconstruire sans risque les valeurs tuple et frozenset.

  • Emplacement de l’API (décision de conception #94) : les méthodes de sérialisation (to_json, from_json, to_pickle, from_pickle) sont définies sur _StackedDict et délèguent aux fonctions privées ci-dessous par des imports différés. Cela crée un cycle d’import accepté entre tools.py et ce module.

Encodage des clés¶

ndict_tools.serialize._encode_key(key: Any) → str¶

Encode une clé _StackedDict en chaîne compatible avec JSON.

JSON impose des clés de type chaîne. Cette fonction associe à toute clé Python hachable prise en charge une chaîne unique et réversible. Une clé qui n’est pas une chaîne est écrite entre crochets : son repr() pour int, float, bool et tuple (entier 42 → "[42]", tuple (1, 2) → "[(1, 2)]"), et frozenset{...} pour un frozenset. Une clé chaîne est transmise telle quelle, sauf si elle commence par [ : elle est alors échappée par une barre oblique inverse ("[42]" → "\[42]"), afin de ne pas être relue comme une clé encodée.

Paramètres:

key (Any) – La clé à encoder. Types pris en charge : str, int, float, bool, tuple plat de scalaires, frozenset plat de scalaires.

Renvoie:

Une chaîne compatible avec JSON qui représente la clé.

Type renvoyé:

str

Lève:

StackedTypeError – Si key est d’un type non pris en charge.

Exemples

>>> _encode_key("hello")
'hello'
>>> _encode_key("[42]")
'\\[42]'
>>> _encode_key(42)
'[42]'
>>> _encode_key(3.14)
'[3.14]'
>>> _encode_key(True)
'[True]'
>>> _encode_key((1, 2))
'[(1, 2)]'
>>> _encode_key(frozenset({1, 2}))
'[frozenset{1, 2}]'

Notes

  • bool est testé avant int parce que bool est une sous-classe de int.

  • Les valeurs float utilisent repr() pour conserver toute leur précision.

  • Un frozenset n’est pas ordonné : l’ordre des éléments dans la forme encodée n’est pas garanti. L’aller-retour conserve l’égalité des ensembles, pas l’ordre des éléments.

ndict_tools.serialize._decode_key(encoded: str) → Any¶

Décode une clé JSON encodée vers son type Python d’origine.

Inverse _encode_key selon les cinq règles énumérées dans les notes ci-dessous : une chaîne échappée, un frozenset, un tuple, un scalaire entre crochets, ou une chaîne simple.

Aucun eval() n’est utilisé. ast.literal_eval() n’est utilisé que pour des tuples plats de scalaires Python, qui sont par définition des littéraux Python valides.

Paramètres:

encoded (str) – La chaîne de clé JSON encodée produite par _encode_key.

Renvoie:

La clé Python d’origine.

Type renvoyé:

Any

Exemples

>>> _decode_key("hello")
'hello'
>>> _decode_key('\\[42]')
'[42]'
>>> _decode_key("[42]")
42
>>> _decode_key("[3.14]")
3.14
>>> _decode_key("[True]")
True
>>> _decode_key("[(1, 2)]")
(1, 2)
>>> _decode_key("[frozenset{1, 2}]")
frozenset({1, 2})

Notes

Règles de décodage (appliquées dans l’ordre) :

  1. Commence par \[ → retirer \, renvoyer comme str.

  2. Commence par [frozenset{ et se termine par }] → analyser la liste CSV de scalaires qu’elle contient, renvoyer comme frozenset.

  3. Commence par [( et se termine par )] → ast.literal_eval(), renvoyer comme tuple.

  4. Commence par [ et se termine par ] → déduire le type du scalaire (True/False → bool ; . ou e → float ; sinon int).

  5. Sinon → renvoyer comme str, sans modification.

Encodeur JSON¶

class ndict_tools.serialize.NestedDictionaryEncoder(*, skipkeys=False, ensure_ascii=True, check_circular=True, allow_nan=True, sort_keys=False, indent=None, separators=None, default=None)¶

Bases : JSONEncoder

Encodeur JSON pour les instances de _StackedDict.

Encode les _StackedDict (et leurs sous-classes) en dict imbriqués simples, en appliquant _encode_key à toutes les clés qui ne sont pas des chaînes, afin que la sortie JSON soit valide et entièrement réversible.

Utilisé en interne par _StackedDict.to_json. Ne fait pas partie de l’API publique.

Exemples

>>> import json
>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({"a": {"b": 1}})
>>> json.dumps(nd, cls=NestedDictionaryEncoder)
'{"a": {"b": 1}}'
default(o: Any) → Any¶

Implémentez cette méthode dans une sous-classe de sorte qu’elle renvoie un objet sérialisable pour o, ou qu’elle appelle l’implémentation de base (pour lever une TypeError).

Par exemple, pour prendre en charge des itérateurs quelconques, vous pourriez implémenter default ainsi

def default(self, o):
    try:
        iterable = iter(o)
    except TypeError:
        pass
    else:
        return list(iterable)
    # La méthode default de la classe de base lève une TypeError
    return super().default(o)
encode(o: Any) → str¶

Renvoie une représentation sous forme de chaîne JSON d’une structure de données Python.

>>> from json.encoder import JSONEncoder
>>> JSONEncoder().encode({"foo": ["bar", "baz"]})
'{"foo": ["bar", "baz"]}'
iterencode(o: Any, _one_shot: bool = False) → Iterator[str]¶

Encode l’objet donné et produit chaque représentation sous forme de chaîne dès qu’elle est disponible.

Par exemple

for chunk in JSONEncoder().iterencode(bigobject):
    mysocket.write(chunk)
ndict_tools.serialize._make_decoder_hook(cls: type, class_options: dict[str, Any]) → Callable[[...], Any]¶

Renvoie un object_pairs_hook qui reconstruit un _StackedDict (ou une sous-classe) à partir des paires clé-valeur JSON.

Paramètres:

  • cls (type) – La sous-classe de _StackedDict à instancier.

  • class_options (dict) – Arguments nommés transmis à cls.from_dict. default_setup est facultatif et résolu par cls._normalize_setup.

Renvoie:

Un hook utilisable avec json.load(..., object_pairs_hook=hook).

Type renvoyé:

Callable

Fonctions pickle¶

ndict_tools.serialize._pickle_dump(nd: Any, path: str | Path, protocol: int | None = None) → None¶

Écrit un _StackedDict dans un fichier pickle, accompagné d’un fichier d’empreinte SHA-256.

Écrit deux fichiers : - <path> — le fichier pickle - <path>.sha256 — l’empreinte hexadécimale des octets du fichier pickle

Paramètres:

  • nd (_StackedDict) – L’objet à enregistrer avec pickle.

  • path (str or Path) – Chemin du fichier de destination.

  • protocol (int, optional) – Protocole pickle (par défaut : pickle.DEFAULT_PROTOCOL).

Avertissements:

UserWarning – Émet toujours un avertissement rappelant aux appelants que pickle n’est pas sûr avec des fichiers non fiables.

ndict_tools.serialize._pickle_load(path: str | Path, verify: bool = True) → Any¶

Charge un _StackedDict depuis un fichier pickle, en vérifiant éventuellement son fichier d’empreinte SHA-256.

Paramètres:

  • path (str or Path) – Chemin du fichier pickle.

  • verify (bool, optional) – Si True (par défaut), lit le fichier d’empreinte .sha256 et lève une StackedValueError si l’empreinte ne correspond pas ou si ce fichier est absent.

Renvoie:

L’objet désérialisé.

Type renvoyé:

Any

Lève:

StackedValueError – Si verify=True et que l’empreinte ne correspond pas ou que le fichier d’empreinte est absent.

Avertissements:

UserWarning – Émet toujours un avertissement rappelant aux appelants que pickle n’est pas sûr avec des fichiers non fiables.
