tools — Infrastructure principale¶

Avertissement

Module interne — peut changer sans préavis. N’importez pas ces objets et n’en héritez pas dans du code de production.

Ce module fournit l’infrastructure technique principale de manipulation des dictionnaires imbriqués. Bien qu’il soit masqué de l’API publique du paquet, il sert de fondation à toutes les opérations sur les dictionnaires imbriqués.

  • _StackedDict : classe de base des structures de dictionnaires imbriqués

  • _HKey : nœud d’arbre représentant les clés hiérarchiques (privé, optimisé avec des tuples)

  • _Paths : vue de tous les chemins d’un dictionnaire imbriqué

  • _CPaths : représentation compacte, ou factorisée, des chemins des dictionnaires imbriqués

Le module permet de naviguer dans des structures de dictionnaires profondément imbriquées, de les interroger et de les factoriser efficacement, avec prise en charge de divers types de clés.

La classe _StackedDict est le moteur central du paquet ndict_tools. Elle implémente tous les attributs, méthodes et mécanismes fondamentaux nécessaires pour initialiser, gérer et manipuler des dictionnaires imbriqués. Cette classe est conçue pour :

  • Orchestrer les briques de base des fonctionnalités de dictionnaire imbriqué

  • Fournir l’outillage complet pour l’imbrication des dictionnaires, la gestion des clés et les opérations sur les données hiérarchiques

  • Servir de base polyvalente aux implémentations de dictionnaires actuelles et futures

ndict_tools.tools.compare_dict(d1: Any, d2: Any) → bool¶

Compare récursivement l’égalité de deux structures éventuellement imbriquées.

Effectue une comparaison profonde de dictionnaires, listes, tuples, ensembles et valeurs scalaires. Deux structures sont considérées comme égales si elles ont le même type et un contenu égal à tous les niveaux d’imbrication.

Paramètres:

  • d1 (Any) – Première structure à comparer

  • d2 (Any) – Seconde structure à comparer

Renvoie:

True si les structures sont identiques en type et en contenu

Type renvoyé:

bool

Exemples

>>> compare_dict({'a': 1}, {'a': 1})
True
>>> compare_dict({'a': {'b': 1}}, {'a': {'b': 1}})
True
>>> compare_dict({'a': 1}, {'a': 2})
False
>>> compare_dict([1, 2], (1, 2))
False

Notes

  • La vérification des types est stricte : [1, 2] != (1, 2), même avec les mêmes valeurs

  • Les ensembles de clés des dictionnaires doivent correspondre exactement

  • Traite récursivement les structures imbriquées de profondeur quelconque

ndict_tools.tools.unpack_items(dictionary: dict[Any, Any]) → Generator[tuple[tuple[Any, ...], Any], None, None]¶

Aplatit récursivement un dictionnaire imbriqué en paires (chemin, valeur).

Parcourt une structure de dictionnaire imbriqué et produit chaque valeur terminale avec son chemin hiérarchique, représenté par un tuple de clés. Les dictionnaires vides sont conservés et produits avec leur chemin.

Paramètres:

dictionary (dict) – Dictionnaire à décomposer (éventuellement imbriqué)

Produit:

tuple – (path_tuple, valeur), où path_tuple est le tuple des clés qui mènent à la valeur

Exemples

>>> list(unpack_items({'a': 1, 'b': {'c': 2}}))
[(('a',), 1), (('b', 'c'), 2)]
>>> list(unpack_items({'a': {}}))
[(('a',), {})]
>>> list(unpack_items({'a': {'b': {'c': 1}}}))
[(('a', 'b', 'c'), 1)]

Notes

  • Utilise un parcours en profondeur

  • Les dictionnaires vides sont traités comme des valeurs terminales

  • Les chemins sont représentés par des tuples immuables, donc hachables

_HKey — Nœud de clé hiérarchique¶

class ndict_tools.tools._HKey(key: Any, parent: _HKey | None = None, is_root: bool = False)¶

Bases : object

Nœud d’arbre privé représentant une clé hiérarchique dans un dictionnaire imbriqué.

Chaque instance de _HKey représente une seule clé d’une structure de dictionnaire imbriqué, et forme un arbre dans lequel :

  • Chaque nœud contient une clé du dictionnaire

  • Les nœuds enfants (stockés dans des tuples immuables) représentent les clés des dictionnaires imbriqués

  • Les références au parent permettent de reconstruire le chemin depuis n’importe quel nœud

L’utilisation de tuples immuables pour les enfants optimise l’occupation mémoire et les performances d’itération des algorithmes de parcours d’arbre (en profondeur, en largeur).

Avertissement

C’est une classe privée (préfixe tiret bas) qui ne doit pas être instanciée directement par du code externe. Accédez-y par CompactPathsView ou NestedDictionary.

Paramètres:

  • key (Any) – La clé que représente ce nœud

  • parent (Optional[_HKey], optional) – Référence au nœud parent, None pour les nœuds racines

  • is_root (bool, optional) – Indique si ce nœud est un nœud racine, False par défaut

dfs_preorder(visit: Callable[[_HKey], None] | None = None) → Iterator[_HKey]¶

Parcours en profondeur dans l’ordre préfixe (le nœud, puis ses enfants).

Ordre préfixe : visite le nœud courant avant ses enfants. Ordre : racine → sous-arbre gauche → sous-arbre droit

Ce parcours résiste aux cycles : si la structure sous-jacente contient des cycles (ce qui ne doit pas arriver dans un arbre valide), les nœuds déjà vus sont ignorés afin d’éviter les boucles infinies.

Paramètres:

visit (Optional[Callable[[_HKey], None]],) – Fonction de rappel facultative, appelée sur chaque nœud

Produit:

_HKey – Chaque nœud, dans l’ordre préfixe

Exemples

>>> root = _HKey.build_forest({'a': {'b': 1, 'c': 2}})
>>> keys = [node.key for node in root.dfs_preorder() if not node.is_root]
>>> keys

bfs(visit: Callable[[_HKey], None] | None = None) → Iterator[_HKey]¶

Parcours en largeur (par niveau).

Le parcours en largeur explore tous les nœuds de profondeur N avant de passer à la profondeur N+1. Utilise une file (deque) pour des opérations en O(1).

Ce parcours résiste aux cycles : les nœuds déjà vus ne sont pas remis dans la file, ce qui évite les boucles infinies en présence de cycles.

Paramètres:

visit (Optional[Callable[[_HKey], None]]) – Fonction de rappel facultative, appelée sur chaque nœud

Produit:

_HKey – Chaque nœud, dans l’ordre par niveau

Exemples

>>> root = _HKey.build_forest({'a': {'b': {'c': 1}}})
>>> keys = [node.key for node in root.bfs() if not node.is_root]
>>> keys
['a', 'b', 'c']

>>> # Parcours en largeur avec suivi de la profondeur
>>> root = _HKey.build_forest({'a': {'b': 1, 'c': 2}, 'd': 3})

...         print(f"Depth {node.get_depth()}: {node.key}")

Depth 0: d
Depth 1: b
Depth 1: c

prune(predicate: Callable[[_HKey], bool]) → _HKey¶

Crée un nouvel arbre qui ne contient que les nœuds satisfaisant le prédicat et leurs ancêtres.

Cette méthode réalise un « élagage avec préservation des chemins » : elle filtre l’arbre pour ne garder que les branches qui mènent à des nœuds satisfaisant le prédicat. Tous les nœuds ancêtres sont conservés automatiquement afin de préserver la connexité de l’arbre et sa structure hiérarchique.

L’algorithme :

  1. Repère tous les nœuds qui satisfont le prédicat

  2. Conserve tous les ancêtres des nœuds correspondants pour préserver les chemins

  3. Supprime toutes les autres branches

  4. Renvoie un nouvel arbre (l’original n’est pas modifié)

Paramètres:

Classe de base interne des structures de dictionnaires imbriqués hiérarchiques.

_StackedDict est le moteur central qui fonde toutes les opérations sur les dictionnaires imbriqués du paquet ndict_tools. Il étend le defaultdict de Python avec la prise en charge des clés hiérarchiques, l’accès par chemin et des méthodes de parcours spécialisées.

Fonctionnalités principales :

  • Clés hiérarchiques : des listes servent de clés pour atteindre les valeurs imbriquées : d[['a', 'b', 'c']]

  • Imbrication automatique : écrire par un chemin crée les niveaux intermédiaires manquants

  • Vues des chemins : accès à tous les chemins par paths() et compact_paths()

  • Parcours d’arbre : algorithmes de parcours en profondeur et en largeur pour la navigation

  • Opérations profondes : méthodes spécialisées de copie, d’égalité et de conversion

Avertissement

C’est une classe privée (préfixe tiret bas) qui ne doit pas être instanciée directement par du code externe. Accédez-y par NestedDictionary ou ses sous-classes.

Les développeurs peuvent néanmoins l’utiliser directement pour des implémentations personnalisées, comme le décrit la documentation d’utilisation.

_CPaths — Vue des chemins compacts¶

class ndict_tools.tools._CPaths(stacked_dict: _StackedDict | None = None)¶

Bases : _Paths

Une vue paresseuse qui donne une représentation compacte des chemins hiérarchiques.

Étend _Paths pour fournir une représentation factorisée, ou compacte, dans laquelle la structure hiérarchique est représentée par des listes imbriquées : - nœuds feuilles : la clé seule - nœuds internes : [clé, enfant1, enfant2, …]

Dans une liste de nœud, chaque élément après le premier est un enfant du premier : ['b', 'c', 'd'] est b avec deux enfants, tandis que ['b', ['c', 'd']] est la chaîne b, c, d.

Les chemins et la structure compacte se convertissent dans les deux sens : - chemins → structure compacte (factorisation), qui donne la forme canonique - structure compacte → chemins (développement)

Chaque ensemble de chemins a exactement une forme canonique. D’autres structures sont acceptées et peuvent se développer en les mêmes chemins, comme ['a'] pour la feuille 'a'.

Avertissement

C’est une classe privée (préfixe tiret bas) qui ne doit pas être instanciée directement par du code externe.

stacked_dict (_StackedDict) – Le dictionnaire imbriqué dont on crée une vue compacte

is_covering(stacked_dict: _StackedDict) → bool¶

Teste si cette vue décrit exactement les chemins d’un dictionnaire imbriqué.

Avec S l’ensemble des chemins développés à partir de cette structure et T l’ensemble des chemins de stacked_dict, le résultat est S == T. C’est plus strict qu’une couverture complète : coverage() renvoie 1.0 dès que T est inclus dans S, tandis que is_covering() exige en plus que S ne contienne aucun autre chemin.

Paramètres:

stacked_dict (NestedDictionary) – Le dictionnaire imbriqué de comparaison (de n’importe quelle classe de la famille)

Renvoie:

True si les deux ensembles de chemins sont égaux

Type renvoyé:

bool

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1}, 'c': 2})
>>> c_paths = nd.compact_paths()
>>> c_paths.is_covering(nd)
True

>>> # Couverture partielle
>>> c_paths.structure = [['a']]  # Ne couvre que 'a', ni 'a.b' ni 'c'
>>> c_paths.is_covering(nd)
False

>>> # Tous les chemins de nd et un de plus : couverture totale, sans égalité
>>> c_paths.structure = [['a', 'b'], 'c', 'e']
>>> c_paths.coverage(nd), c_paths.is_covering(nd)
(1.0, False)

Notes

Pour une vue créée à partir du dictionnaire imbriqué auquel on la compare : nd.compact_paths().is_covering(nd) renvoie toujours True, car la structure compacte est construite à partir de tous les chemins de nd.

coverage(stacked_dict: _StackedDict) → float¶

Calcule la part des chemins d’un dictionnaire imbriqué présents dans cette vue.

Avec S l’ensemble des chemins développés à partir de cette structure et T l’ensemble des chemins de stacked_dict, la couverture vaut len(S & T) / len(T). Les chemins de S absents de T ne la modifient pas ; la valeur reste donc comprise entre 0.0 et 1.0. Lorsque T est vide, le résultat vaut 1.0 si S est vide aussi, et 0.0 sinon.

Paramètres:

stacked_dict (NestedDictionary) – Le dictionnaire imbriqué de comparaison (de n’importe quelle classe de la famille)

Renvoie:

Couverture comprise entre 0.0 et 1.0

Type renvoyé:

float

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1, 'c': 2}, 'd': 3})
>>> c_paths = nd.compact_paths()
>>> c_paths.coverage(nd)
1.0

>>> # Couverture partielle : seulement 'a' et 'a.b' sur 4 chemins
>>> c_paths.structure = [['a', 'b']]
>>> c_paths.coverage(nd)
0.5

>>> # Des chemins en trop ne portent pas la valeur au-delà de 1.0
>>> c_paths.structure = [['a', 'b', 'c'], ['d'], ['e']]
>>> c_paths.coverage(nd)
1.0

Notes

Pour une vue créée à partir du dictionnaire imbriqué auquel on la compare : nd.compact_paths().coverage(nd) renvoie toujours 1.0, car tous les chemins de nd sont inclus.

Utilisez missing_paths() pour énumérer les chemins en trop et is_covering() pour vérifier que les deux ensembles sont égaux.
