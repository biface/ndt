Classes de dictionnaire et de chemins¶

Ce module fournit des outils et une classe pour créer des dictionnaires imbriqués, puisque Python standard n’a pas de dictionnaires imbriqués.

Classes de dictionnaire¶

class ndict_tools.NestedDictionary(*args: Mapping[Any, Any] | Iterable[tuple[Any, Any]], default_setup: Mapping[str, Any] | None = None, **kwargs: Any)¶

Classe de dictionnaire imbriqué.

Cette classe est conçue comme un dictionnaire empilé. Elle représente un emboîtement de dictionnaires, c’est-à-dire que chaque clé est une valeur ou un dictionnaire imbriqué. Et ainsi de suite…

Paramètres:

  • *args (Mapping or iterable of (key, value) pairs) – Données initiales. Les dictionnaires simples imbriqués sont convertis récursivement.

  • default_setup (Mapping[str, Any], optional) – Configuration (argument nommé uniquement) avec les clés “indent” et “default_factory”. Lorsqu’elle est omise ou vide, {'indent': 0, 'default_factory': NestedDictionary} est utilisée. Pour obtenir un comportement strict, utilisez StrictNestedDictionary ou passez 'default_factory': None.

  • **kwargs (Any) – Données initiales fournies comme arguments nommés. Ce sont des données, pas des réglages : NestedDictionary(indent=2) crée une clé 'indent'.

Exemples

>>> from ndict_tools import NestedDictionary
>>> # À partir d’un dictionnaire
>>> nd1 = NestedDictionary({'first': 1, 'second': {'1': "2:1", '2': "2:2"}, 'third': 3})
>>> nd1['second']['2']
'2:2'

>>> # À partir d’un itérable de paires (clé, valeur)
>>> nd2 = NestedDictionary(zip(['first', 'second', 'third'],
...                            [1, {'1': "2:1", '2': "2:2"}, 3]))
>>> nd3 = NestedDictionary([('first', 1), ('second', {'1': "2:1", '2': "2:2"}),
...                         ('third', 3)])
>>> nd1 == nd2 == nd3
True

>>> # Les dictionnaires simples imbriqués deviennent des niveaux NestedDictionary
>>> type(nd1['second']).__name__
'NestedDictionary'
paths() → PathsView¶

Renvoie une vue de tous les chemins hiérarchiques de ce dictionnaire.

Renvoie une vue paresseuse de tous les chemins, sans les stocker en mémoire. La vue permet l’itération, le calcul de la longueur, les tests d’appartenance et diverses opérations sur les chemins.

Renvoie:

Une vue paresseuse de tous les chemins du dictionnaire imbriqué

Type renvoyé:

PathsView

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1, 'c': 2}, 'd': 3})
>>> paths = nd.paths()
>>> list(paths)
[['a'], ['a', 'b'], ['a', 'c'], ['d']]

>>> # Teste si un chemin existe
>>> ['a', 'b'] in paths
True

>>> # Nombre de chemins
>>> len(paths)
4

>>> # Enfants d’un chemin
>>> paths.get_children(['a'])
['b', 'c']

ancestors(value: Any) → list[Any]¶

Trouve le chemin hiérarchique (les ancêtres) qui mène à une valeur donnée.

Parcourt la structure imbriquée à la recherche de la valeur donnée et renvoie le chemin complet des clés qui y mène, sans la clé finale. Cela renvoie l’« ascendance » de la valeur dans l’arbre.

Paramètres:

value (Any) – Valeur à rechercher dans le dictionnaire imbriqué

Renvoie:

liste des clés formant le chemin vers la valeur (sans la clé finale)

Type renvoyé:

list

Lève:

StackedValueError – Si la valeur est absente du dictionnaire

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': {'c': 1}}})
>>> nd.ancestors(1)
['a', 'b']

>>> nd = NestedDictionary({'a': {'b': 1}, 'c': {'d': 2}})
>>> nd.ancestors(2)
['c']

>>> nd.ancestors(999)
Traceback (most recent call last):
    ...
ndict_tools.exception.StackedValueError: Value 999 not found in the dictionary...

Notes

  • Renvoie le chemin sans la clé finale (parent direct de la valeur)

  • Utilise un parcours en profondeur pour trouver la première occurrence

  • Si la valeur apparaît plusieurs fois, renvoie le premier chemin trouvé

  • Une liste vide est renvoyée pour les valeurs de premier niveau

bfs() → Generator[tuple[tuple[Any, ...], Any], None, None]¶

Parcours en largeur des valeurs terminales.

Parcourt le dictionnaire niveau par niveau à l’aide d’une file, et produit les clés dont la valeur n’est pas un dictionnaire imbriqué, avec leur chemin : toutes celles de profondeur N avant celles de profondeur N+1. Les clés dont la valeur est un dictionnaire imbriqué sont parcourues mais pas produites ; un dictionnaire imbriqué vide ne produit donc rien.

Produit:

tuple – (path_tuple, valeur) pour chaque valeur terminale, dans l’ordre du parcours en largeur

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': {'c': 1}}})
>>> list(nd.bfs())
[(('a', 'b', 'c'), 1)]

>>> nd = NestedDictionary({'a': {'b': 1, 'c': 2}, 'd': 3})
>>> list(nd.bfs())
[(('d',), 3), (('a', 'b'), 1), (('a', 'c'), 2)]

Notes

  • Ne produit que les valeurs terminales, contrairement à dfs(), qui produit aussi les clés dont la valeur est un dictionnaire imbriqué

  • Renvoie les chemins sous forme de tuples immuables

dfs(node: Mapping[Any, Any] | None = None, path: list[Any] | None = None) → Generator[tuple[list[Any], Any], None, None]¶

Parcours en profondeur du dictionnaire imbriqué.

Parcourt récursivement le dictionnaire en profondeur, en produisant chaque chemin hiérarchique (sous forme de liste) et la valeur correspondante. Cela inclut à la fois les nœuds intermédiaires et les valeurs des feuilles.

Paramètres:

  • node (dict, optional) – Nœud courant parcouru (par défaut la racine, self)

  • path (list, optional) – Chemin courant en construction (par défaut une liste vide)

Produit:

tuple – (path_list, valeur) pour chaque nœud, dans l’ordre du parcours en profondeur

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1}, 'c': 2})
>>> for path, value in nd.dfs():
...     if isinstance(value, NestedDictionary):
...         value = value.to_dict()
...     print(path, value)
['a'] {'b': 1}
['a', 'b'] 1
['c'] 2

Notes

  • Visite les nœuds avant leurs enfants (ordre préfixe)

  • Renvoie les chemins sous forme de listes mutables (contrairement à unpacked_keys)

  • Inclut les nœuds intermédiaires de type dictionnaire

  • Utile pour les opérations sur les arbres

Voir aussi

bfs

Parcours en largeur

unpacked_items

Semblable, mais seulement les valeurs terminales

equal(other: object) → bool¶

Teste l’égalité : même classe, même configuration et même contenu.

Deux dictionnaires imbriqués sont égaux s’ils ont : 1. exactement la même classe (pas une sous-classe) 2. la même configuration default_setup 3. la même structure et les mêmes valeurs

C’est la comparaison la plus stricte, et celle qu’utilise ==.

Paramètres:

other (object) – Objet à comparer

Renvoie:

True si toutes les conditions sont remplies

Type renvoyé:

bool

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd1 = NestedDictionary({'a': 1})
>>> nd2 = NestedDictionary({'a': 1})
>>> nd1.equal(nd2)
True

>>> # Configuration différente
>>> nd3 = NestedDictionary(
...     {'a': 1},
...     default_setup={'indent': 4, 'default_factory': NestedDictionary},
... )
>>> nd1.equal(nd3)
False

classmethod from_dict(dictionary: dict[Any, Any], **class_options: Any) → Self¶

Convertit récursivement un dictionnaire standard en dictionnaire imbriqué de cette classe.

Constructeur alternatif qui transforme un dictionnaire imbriqué ordinaire en instance de la classe sur laquelle il est appelé. La classe cible est cls elle-même, ce qui évite de passer la classe explicitement et prévient les erreurs dans les appels récursifs.

Paramètres:

  • dictionary (dict) – Le dictionnaire à transformer (éventuellement imbriqué).

  • **class_options (dict) – Options d’initialisation, passées à cls à chaque niveau. default_setup est facultatif : comme pour le constructeur, la configuration est résolue par cls._normalize_setup, qui fournit la configuration par défaut de la classe lorsqu’aucune n’est donnée.

Renvoie:

Nouvelle instance de la classe appelante contenant la structure du dictionnaire.

Type renvoyé:

Self

Lève:

StackedKeyError – Si default_setup est absent et que cls ne définit aucune configuration par défaut.

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary.from_dict({'a': {'b': 1}})
>>> nd['a']['b']
1
>>> strict = NestedDictionary.from_dict(
...     {'a': {'b': 1}},
...     default_setup={'indent': 0, 'default_factory': None}
... )

Notes

  • Les valeurs qui sont déjà des dictionnaires imbriqués de la famille sont conservées telles quelles.

  • Les valeurs dict ordinaires sont converties récursivement avec cls.

  • Les valeurs qui ne sont pas des dictionnaires sont affectées directement.

Voir aussi

to_dict

Opération inverse.

classmethod from_json(path: str | Path, **class_options: Any) → Self¶

Reconstruit un dictionnaire imbriqué de cette classe à partir d’un fichier JSON.

Les clés écrites entre crochets par to_json sont décodées vers leur type Python d’origine ; les clés chaînes échappées perdent leur échappement. L’aller-retour est sans perte pour les types pris en charge : str, int, float, bool, tuple plat, frozenset plat.

Paramètres:

  • path (str or Path) – Chemin du fichier JSON.

  • **class_options (dict) – Passé à cls.from_dict. Le fichier JSON ne contient aucune configuration : default_setup la fournit et, en son absence, cls._normalize_setup fournit la configuration par défaut de la classe.

Renvoie:

Instance reconstruite de la classe appelante.

Type renvoyé:

Self

Lève:

StackedTypeError – Si la racine du document JSON n’est pas un objet (par exemple une liste ou un scalaire), si bien qu’aucune instance de la classe appelante n’est construite.

Exemples

>>> from ndict_tools import NestedDictionary
>>> import tempfile
>>> from pathlib import Path
>>> tmp = tempfile.TemporaryDirectory()
>>> path = Path(tmp.name) / 'nd.json'
>>> NestedDictionary({'a': {'b': 1}}).to_json(path)
>>> nd = NestedDictionary.from_json(path)
>>> nd.to_dict()
{'a': {'b': 1}}
>>> strict = NestedDictionary.from_json(
...     path,
...     default_setup={'indent': 0, 'default_factory': None}
... )
>>> strict.default_factory is None
True
>>> tmp.cleanup()

Sérialise dans un fichier JSON.

height() → int¶

Calcule le nombre de niveaux de la structure imbriquée.

C’est le nombre de clés du chemin le plus long. Les clés de premier niveau sont à la profondeur 0 ; le résultat est donc la plus grande profondeur d’une clé plus 1. Un dictionnaire vide a une hauteur de 0.

Renvoie:

Nombre de clés du chemin le plus long

Type renvoyé:

int

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': 1})
>>> nd.height()
1

>>> nd = NestedDictionary({'a': {'b': {'c': 1}}})
>>> nd.height()
3

>>> nd = NestedDictionary()
>>> nd.height()
0

Notes

  • Un dictionnaire vide a une hauteur de 0

  • Un dictionnaire à un seul niveau a une hauteur de 1

  • Complexité O(n), où n est le nombre de chemins

Voir aussi

is_balanced() → bool¶

Teste si la structure imbriquée est équilibrée en hauteur.

Un dictionnaire équilibré est un dictionnaire dans lequel la différence de hauteur entre deux sous-arbres quelconques d’un même niveau est d’au plus 1. Cela indique une répartition relativement uniforme de la profondeur d’imbrication.

Renvoie:

True si la structure est équilibrée, False sinon

Type renvoyé:

bool

Exemples

>>> from ndict_tools import NestedDictionary
>>> # Équilibré
>>> nd = NestedDictionary({'a': {'b': 1}, 'c': {'d': 2}})
>>> nd.is_balanced()
True

>>> # Déséquilibré
>>> nd = NestedDictionary({'a': {'b': {'c': 1}}, 'd': 2})
>>> nd.is_balanced()
False

Notes

  • Utilise un calcul récursif de la hauteur

  • Vérifie l’équilibre à chaque nœud

  • Un dictionnaire vide est considéré comme équilibré

  • Utile pour repérer les structures déséquilibrées

Voir aussi

height

Renvoie la profondeur maximale

isomorph(other: object) → bool¶

Teste si deux dictionnaires imbriqués sont isomorphes.

Deux structures sont isomorphes si : 1. ce sont toutes deux des dictionnaires imbriqués (de n’importe quelle classe de la famille) 2. elles ont le même contenu (clés et valeurs)

Elles décrivent la même structure imbriquée, au choix de la classe près : un NestedDictionary et un StrictNestedDictionary de même contenu ne diffèrent que par l’effet de la lecture d’une clé absente. Les différences de configuration sont ignorées. Un dict simple n’est jamais isomorphe.

Paramètres:

other (object) – Objet à comparer

Renvoie:

True si les deux sont des dictionnaires imbriqués de même contenu

Type renvoyé:

bool

Exemples

>>> from ndict_tools import NestedDictionary
>>> from ndict_tools import StrictNestedDictionary
>>> nd1 = NestedDictionary({'a': 1})
>>> nd2 = StrictNestedDictionary({'a': 1})
>>> nd1.equal(nd2)
False
>>> nd1.isomorph(nd2)
True
>>> nd1.isomorph({'a': 1})
False

leaves() → list[Any]¶

Extrait les valeurs de toutes les clés feuilles de la structure imbriquée.

Une feuille est une clé sans enfant : sa valeur n’est pas un dictionnaire imbriqué, ou en est un vide. Renvoie les valeurs de ces clés.

Renvoie:

liste de toutes les valeurs des feuilles

Type renvoyé:

list

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1}, 'c': 2})
>>> nd.leaves()
[1, 2]

>>> nd = NestedDictionary({'a': {'b': {'c': 1}}})
>>> nd.leaves()
[1]

>>> # Un dict vide comme valeur de feuille
>>> nd = NestedDictionary({'a': {}})
>>> [type(value).__name__ for value in nd.leaves()]
['NestedDictionary']

Notes

  • Renvoie les valeurs dans l’ordre du parcours en profondeur

  • Les dictionnaires vides sont considérés comme des valeurs de feuilles

  • Les dict simples (qui ne sont pas des dictionnaires imbriqués de la famille) sont aussi des feuilles

Nombre d’occurrences (0 si la clé n’existe pas)

Met à jour le dictionnaire imbriqué avec les paires clé/valeur d’un mapping, d’un itérable ou d’arguments nommés.

Fusionne dans ce dictionnaire imbriqué le mapping, l’itérable de paires clé-valeur ou les arguments nommés fournis, en convertissant récursivement les dict ordinaires en niveaux imbriqués et en conservant les dictionnaires imbriqués déjà fournis. class ndict_tools.CompactPathsView(stacked_dict: NestedDictionary | None = None)¶

Une vue qui donne une représentation compacte des chemins hiérarchiques.

Fournit une représentation factorisée, ou compacte, dans laquelle la structure hiérarchique est représentée par des listes imbriquées. C’est utile pour représenter et manipuler efficacement des structures de chemins, en particulier lorsqu’il y a beaucoup de chemins semblables.

La structure compacte utilise des listes imbriquées où :

  • Les nœuds feuilles sont représentés par leur seule clé

  • Les nœuds internes sont représentés par [clé, enfant1, enfant2, …]

Une structure construite à partir d’un dictionnaire est la forme canonique de ses chemins, et la conversion fonctionne dans les deux sens.

Paramètres:

stacked_dict (NestedDictionary) – Le dictionnaire imbriqué dont on crée une vue compacte (de n’importe quelle classe de la famille NestedDictionary)

Exemples

>>> from ndict_tools import NestedDictionary, PathsView
>>> nd = NestedDictionary({'a': {'b': 1, 'c': 2}, 'd': 3})
>>> cpaths = nd.compact_paths()
>>> type(cpaths).__name__
'CompactPathsView'

>>> # Structure compacte
>>> cpaths.structure
[['a', 'b', 'c'], 'd']

>>> # Développe en chemins complets
>>> cpaths.expand()
[['a'], ['a', 'b'], ['a', 'c'], ['d']]

>>> # Parcourt les chemins développés, comme avec un PathsView
>>> list(cpaths)
[['a'], ['a', 'b'], ['a', 'c'], ['d']]

>>> # Affecte une structure personnalisée
>>> cpaths.structure = [['x', 'y', 'z']]
>>> cpaths.expand()
[['x'], ['x', 'y'], ['x', 'z']]

>>> # Vérifie la couverture du dictionnaire d’origine
>>> cpaths = nd.compact_paths()
>>> cpaths.is_covering(nd)
True
>>> cpaths.coverage(nd)
1.0

>>> # Structure partielle
>>> cpaths.structure = [['a', 'b']]
>>> cpaths.coverage(nd)
0.5
>>> cpaths.uncovered_paths(nd)
[['a', 'c'], ['d']]

Notes

Format de la structure compacte :

  • Feuille simple : 'key'

  • Nœud avec enfants : ['key', child1, child2, ...]

Exemples de structures compactes :

  • [['a'], ['b']] → deux chemins indépendants : ['a'] et ['b']

  • [['a', 'b', 'c']] → chemins : ['a'], ['a', 'b'], ['a', 'c']

  • [['a', ['b', 'c']]] → chemins : ['a'], ['a', 'b'], ['a', 'b', 'c'] (une liste imbriquée est un enfant qui a lui-même des enfants)

coverage(stacked_dict: NestedDictionary) → float¶

Calcule la part des chemins d’un dictionnaire imbriqué présents dans cette vue.

Avec S l’ensemble des chemins développés à partir de cette structure et T l’ensemble des chemins de stacked_dict, la couverture vaut len(S & T) / len(T). Les chemins de S absents de T ne la modifient pas ; la valeur reste donc comprise entre 0.0 et 1.0. Lorsque T est vide, le résultat vaut 1.0 si S est vide aussi, et 0.0 sinon.

Paramètres:

stacked_dict (NestedDictionary) – Le dictionnaire imbriqué de comparaison (de n’importe quelle classe de la famille)

Renvoie:

Couverture comprise entre 0.0 et 1.0

Type renvoyé:

float

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1, 'c': 2}, 'd': 3})
>>> c_paths = nd.compact_paths()
>>> c_paths.coverage(nd)
1.0

>>> # Couverture partielle : seulement 'a' et 'a.b' sur 4 chemins
>>> c_paths.structure = [['a', 'b']]
>>> c_paths.coverage(nd)
0.5

>>> # Des chemins en trop ne portent pas la valeur au-delà de 1.0
>>> c_paths.structure = [['a', 'b', 'c'], ['d'], ['e']]
>>> c_paths.coverage(nd)
1.0

Notes

Pour une vue créée à partir du dictionnaire imbriqué auquel on la compare : nd.compact_paths().coverage(nd) renvoie toujours 1.0, car tous les chemins de nd sont inclus.

Utilisez missing_paths() pour énumérer les chemins en trop et is_covering() pour vérifier que les deux ensembles sont égaux.

static expand_structure(structure: list[Any]) → list[list[Any]]¶

Développe une structure compacte en chemins complets.

C’est l’opération inverse de la factorisation. Plusieurs structures peuvent se développer en les mêmes chemins ; la structure construite à partir d’un dictionnaire est la structure canonique, et chaque ensemble de chemins a exactement une structure canonique.

Paramètres:

structure (list[Any]) – Structure compacte à développer

Renvoie:

Tous les chemins développés

Type renvoyé:

list[list[Any]]

Exemples

>>> from ndict_tools import CompactPathsView
>>> structure = ['a', ['b', 'c', 'd']]
>>> CompactPathsView.expand_structure(structure)
[['a'], ['b'], ['b', 'c'], ['b', 'd']]

>>> # Dans une liste de nœud, une liste imbriquée est une chaîne, pas des nœuds frères
>>> CompactPathsView.expand_structure([['b', ['c', 'd']]])
[['b'], ['b', 'c'], ['b', 'c', 'd']]

>>> structure = [['x', ['y', 'z1', 'z2'], 'a']]
>>> CompactPathsView.expand_structure(structure)
[['x'], ['x', 'y'], ['x', 'y', 'z1'], ['x', 'y', 'z2'], ['x', 'a']]

is_covering(stacked_dict: NestedDictionary) → bool¶

Teste si cette vue décrit exactement les chemins d’un dictionnaire imbriqué.

Avec S l’ensemble des chemins développés à partir de cette structure et T l’ensemble des chemins de stacked_dict, le résultat est S == T. C’est plus strict qu’une couverture complète : coverage() renvoie 1.0 dès que T est inclus dans S, tandis que is_covering() exige en plus que S ne contienne aucun autre chemin.

Paramètres:

stacked_dict (NestedDictionary) – Le dictionnaire imbriqué de comparaison (de n’importe quelle classe de la famille)

Renvoie:

True si les deux ensembles de chemins sont égaux

Type renvoyé:

bool

Exemples

>>> from ndict_tools import NestedDictionary
>>> nd = NestedDictionary({'a': {'b': 1}, 'c': 2})
>>> c_paths = nd.compact_paths()
>>> c_paths.is_covering(nd)
True

>>> # Couverture partielle
>>> c_paths.structure = [['a']]  # Ne couvre que 'a', ni 'a.b' ni 'c'
>>> c_paths.is_covering(nd)
False

>>> # Tous les chemins de nd et un de plus : couverture totale, sans égalité
>>> c_paths.structure = [['a', 'b'], 'c', 'e']
>>> c_paths.coverage(nd), c_paths.is_covering(nd)
(1.0, False)

Notes

Pour une vue créée à partir du dictionnaire imbriqué auquel on la compare : nd.compact_paths().is_covering(nd) renvoie toujours True, car la structure compacte est construite à partir de tous les chemins de nd.
